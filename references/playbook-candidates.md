# Playbook candidates

Lessons, tips, prompts and data sources from this project that other
projects could use, written **client-free**: no client names, people,
addresses, locations tied to the client, record values or identifying
dataset ids. The project code is fine (provenance).

Written by `capture` (tips, gotchas, prompts, data sources) and `remember`
(decisions marked `**Playbook:** candidate`), each committed with a
`playbook-candidate: <one line>` trailer. The weekly harvest reads only this
file and those trailers, and proposes accepted items to the playbook.

Format:

```markdown
### <title>  <!-- YYYY-MM-DD, P0XXXX -->
**Kind:** tip | gotcha | prompt | data source | module idea | decision
**Topic:** arcgis | hydrology | data | container | git-and-files | reports | other
**Context:** <the problem, generically>
**Tip:** <the fix, the exact command or snippet>
**From:** <decision-log entry date + title, if any>
```
